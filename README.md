## Problem Format

Each solution file contains:

* Problem Name
* Clean SQL Query
* Readable Formatting

Example:

```sql
-- LeetCode 181
-- Employees Earning More Than Their Managers

SELECT e.name AS Employee
FROM Employee e
JOIN Employee m
ON e.managerId = m.id
WHERE e.salary > m.salary;
```
